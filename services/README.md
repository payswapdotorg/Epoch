# services/

Reserved for Epoch runtime services (W020+): `agent-runtime` (W020),
`simulation-runner` (W021), `action-gateway` (W022), `marketplace` (W023),
`billing` (W024), `developer-portal` (W025), `document-adapter` (W028),
`security` (W030).

W001 intentionally creates no service packages — each service is introduced by
its owning Work Order (see spec/work-items.md).
