## Product architecture

World Model + Agent System + Constraints + Actions + Simulation/Evaluation + Verification/Evidence + Feedback, wrapped by a shared Experience Runtime and Capability/Adapter Fabric.

## Clients

Web is canonical. Desktop is the power client. Mobile is the field client. All clients share semantic contracts and Experience Protocol.
