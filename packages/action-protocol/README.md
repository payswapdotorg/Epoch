# @epoch/action-protocol

Epoch **Action Protocol v1** — runtime implementation (kernel layer, Work
Order W003). Typed action proposals and authorization request/decision
messages with deterministic, exact-revision evidence addressing.

The published contract surface for this package lives at
`contracts/actions/` (TypeScript declarations, JSON Schema projection,
manifest with digests). This package is the runtime implementation of that
contract; `contracts/actions/parity.ts` proves type identity at compile
time.

## Layer and dependencies

- Epoch layer: `kernel` (declared in `package.json` under `epoch.layer`).
- Runtime dependencies: `zod` and `@epoch/agent-protocol` (workspace,
  kernel → kernel — an allowed layer edge). The agent protocol is the base
  protocol package: it owns the shared admission pipeline (version gate →
  kind gate → zod validation → canonical serialization → digest), the
  shared zod primitives, and the runtime-neutral SHA-256. A future
  `protocol-core` split is recorded as an architecture question in the W003
  PR.
- No Node APIs in runtime code; `node:` imports appear only in tests.

## Public API overview

- `parseActionProposal` / `validateActionProposal` — admit an
  `action.proposal` message. Safety-relevant metadata (preconditions,
  predicted effects ≥ 1, side effects, reversibility, authority
  requirements) is required; unknown fields are rejected.
- `parseAuthorizationRequest` / `validateAuthorizationRequest` — admit an
  `action.authorization-request` (exact proposal revision, requested
  scopes, mandatory justification, optional simulation/evaluation
  context).
- `parseAuthorizationDecision` / `validateAuthorizationDecision` — admit
  an `action.authorization-decision` (authorized with conditions, denied
  with code+reason, or escalated). `decidedBy.role` is structurally
  limited to `action-gateway` and `human-approver`.
- `parseActionProtocolMessage` — discriminating union parser over all
  three message kinds.
- Schemas for every published type (see `src/surface.ts` for the ordered
  registry) plus `renderActionContractFiles()` for the deterministic
  `contracts/actions` emission.

## Authority split (architecture lock rules 2/3)

Agents propose; only the Action Gateway (W022) authorizes and executes.
This package defines the protocol message shapes only — there is no
authorization logic and no runtime orchestration here (W020 owns the agent
runtime, W022 owns the gateway). The split is encoded structurally:
proposals cannot carry decision vocabulary, and authorizer roles exclude
agents by construction.

## Contract artifacts (emission and drift)

`contracts/actions/manifest.json` and `contracts/actions/schemas/*.json`
are committed artifacts generated by `renderActionContractFiles()`; the
drift test re-renders and compares byte-for-byte. Regenerate after an
intentional schema change:

```sh
EPOCH_UPDATE_CONTRACTS=1 pnpm --filter @epoch/action-protocol test contract-drift
```

## Testing

`pnpm --filter @epoch/action-protocol test` runs the vitest suite:
positive round-trips for proposals (all executor kinds, all
reversibility/confidence classifications) and authorization messages (all
decision kinds, all denial codes, exact-digest proposal binding), plus
negative batteries for required safety metadata, authority-requirement
semantics, the authority split (agent-issued decisions are
structurally rejected), shape discipline, envelope gates, provider
neutrality, and contract drift.
